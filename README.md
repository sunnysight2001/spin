# SPIN Selling trainer

Standalone L&D workshop for Medical Representatives. Same player as the Gimliand trainer; this folder contains **only** SPIN.

- 22 slides from the facilitator script
- Facilitator narration + cabin lines on every slide
- Eight languages (English medical terms stay English)
- Neural voice per language via `/api/tts`
- Auto-advance, mic mute, speaker mute

Do **not** copy `gen_spin.py` into this folder. The playable file is `js/deck.js`.
